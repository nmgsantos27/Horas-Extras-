BANCO DE HORAS — Como usar
==========================

COMO INSTALAR NO TELEMÓVEL

1. Abre o link no browser do telemóvel (Chrome ou Safari)
2. Menu (3 pontos) → "Instalar app" ou "Adicionar ao ecrã principal"
3. Confirma — fica um ícone no teu ecrã como uma app normal
4. Abre — funciona offline

ONDE ALOJAR (grátis)

Opção A — Netlify Drop (mais fácil)
1. Vai a https://app.netlify.com/drop
2. Arrasta a pasta "banco-horas" inteira
3. Recebes um link tipo https://xxx.netlify.app
4. Partilha esse link

Opção B — GitHub Pages
1. Cria conta em github.com
2. Cria repositório público
3. Faz upload dos ficheiros
4. Settings → Pages → ativa
5. Link: https://teu-user.github.io/banco-horas

Opção C — Vercel
1. Vai a vercel.com
2. Arrasta a pasta
3. Recebes link

DADOS

- Cada pessoa guarda os seus dados NO PRÓPRIO TELEMÓVEL
- Não há servidor, não há conta, não há login
- Os dados não saem do dispositivo
- Faz backup em Config → Descarregar backup

ATUALIZAR A APP

- Se alojares em Netlify/Vercel: substitui o index.html
- A app atualiza-se sozinha quando abrirem de novo
